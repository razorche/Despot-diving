# Despot Ronilački Klub — portfolio sajt (Budva)

Staticki sajt baziran na Seaflow template mirror-u, prilagođen planu **Plan za Despot.txt**.

## Pokretanje

```bash
npm install
npm run serve
```

http://localhost:3000

## Održavanje

| Komanda | Svrha |
|---------|--------|
| `npm run rework` | Sinhronizuje header/footer/offcanvas, SEO head, zatim copy cleanup |
| `npm run mirror` | Ponovno preuzimanje demo HTML-a (retko potrebno) |

Izvor istine: `Plan za Despot.txt`, `brand/pages-meta.json`, `www/partials/`.

## Stranice (17)

Početna, O nama, Ronjenje (+ detalj), Lokacije (+ detalj), Kursevi (+ detalj), Tim (+ profil), FAQ, Kontakt, Blog (3), Galerija, 404.

Uklonjeno: yacht*, index-2/3 (jahting / privatna plaža demo).

## Napomena

Folder `seaflow-site/` je stari scrape — **nije** deo javnog sajta. Produkcija: Envato licenca pre deploy-a.
